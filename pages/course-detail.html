Learning Outcomes

  • Analyze asymptotic space and time complexities using Big-O, Big-Omega, and Big-Theta notations.
  • Implement balanced tree architectures including AVL trees, Red-Black trees, and Binary Heaps.
  • Master graph algorithms including BFS, DFS, Dijkstra, Bellman-Ford, and Minimum Spanning Trees.
  • Formulate dynamic programming recurrence relations for optimization problems.
